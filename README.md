# AdvanceChatBot
Project Name: GoodSunday – Advanced Messenger-style Chatbot
GoodSunday is a front-end chatbot built using HTML, CSS, and JavaScript. It simulates a real Messenger-style chat experience, complete with chat bubbles, typing animation, emojis, and a custom background image. The chatbot can respond to predefined keywords as well as dynamic user inputs, making it interactive and human-like.
Features:

Messenger-style UI – Separate chat bubbles for user and bot messages.
Typing animation – Bot shows typing dots before replying.
Keyword-based responses – Recognizes common greetings, questions, and topics.
Dynamic fallback responses – Replies even if it doesn’t recognize the input.
Emoji support – Fun and friendly conversation with emojis.
Auto-scroll – Chat always scrolls to the latest message.
Custom background image – Makes the chat visually appealing.
Responsive layout – Works on desktops and tablets.
Front-end only – No backend required; works fully in the browser.

Tech Stack:
HTML5 – Structure of the chat interface
CSS3 – Styling for chat bubbles, layout, background, and animations
JavaScript (ES6) – Handles user input, bot responses, typing animation, and dynamic fallback logic
